# Backend - ممارس

هذا المجلد فيه الـ backend الخاص بالمشروع، ومبني على Laravel 12.

وظيفته يدير الـ API، تسجيل الدخول، الصلاحيات، قواعد البيانات، الإشعارات، وسجل النشاط الخاص بلوحة التحكم.

## أهم الأشياء اللي يديرها الـ backend

- تسجيل الدخول والمصادقة.
- إدارة المستخدمين والأدوار والصلاحيات.
- إدارة الطلاب والمقرئين والمتدربين.
- إدارة الاختبارات والمهام والاختبار النهائي.
- إدارة الإشعارات وسجل النشاط.
- التعامل مع رفع الملفات والمرفقات.

## تشغيل سريع

من داخل هذا المجلد:

تشغيل السيرفر:

```bash
php artisan serve
```

تشغيل الـ migrations:

```bash
php artisan migrate --force
```

تشغيل الاختبارات:

```bash
php artisan test
```

إذا كان المطلوب ربط التخزين العام للملفات:

```bash
php artisan storage:link
```

## الإعدادات

انسخ ملف البيئة المناسب إلى `.env` ثم عدل القيم حسب السيرفر أو البيئة المحلية.

أهم الأشياء اللي تحتاج تضبطها عادة:

- إعدادات قاعدة البيانات.
- `APP_KEY`.
- إعدادات `SANCTUM` و `SESSION` إذا كانت البيئة مختلفة.
- إعدادات `PUSHER` إذا بتستخدم realtime.
- إعدادات `REDIS` إذا بتستخدم cache أو queue.

## ملاحظات تقنية

- المصدر الأساسي لهيكلة قاعدة البيانات موجود في `database/migrations`.
- المشروع يستخدم Laravel Sanctum وFortify للمصادقة.
- الصلاحيات مبنية باستخدام Spatie Permission.
- سجل النشاط مبني باستخدام Spatie Activitylog.
- رفع الملفات يعتمد على Spatie Medialibrary.

## قبل الإطلاق للإنتاج

قبل أي deployment نهائي تأكد من التالي:

1. `APP_ENV=production`
2. `APP_DEBUG=false`
3. إعدادات قاعدة البيانات صحيحة
4. تشغيل `php artisan migrate --force`
5. تشغيل `php artisan storage:link` إذا كان فيه ملفات عامة
6. مراجعة الحزم والتحديثات الأمنية
